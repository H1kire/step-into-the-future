# Городские странники

Статический GPS-RPG прототип для GitHub Pages. Главная страница остаётся `index.html` в корне репозитория.

## Структура

- `index.html` — каркас страницы и подключения ресурсов.
- `css/game.css` — стили, адаптация для телефонов и карта интерфейса.
- `js/game.js` — игровой интерфейс, GPS, бой, инвентарь и локальное сохранение.
- `js/firebase-config.js` — публичная конфигурация Firebase и необязательный ключ App Check.
- `js/firebase-presence.js` — анонимная авторизация и онлайн-видимость игроков.
- `firebase-database.rules.json` — исходный файл правил Realtime Database; GitHub Pages не публикует эти правила автоматически.

## Firebase: защита и публикация

1. В Firebase Authentication включён Anonymous sign-in, а в Authorized domains добавлен домен GitHub Pages.
2.Конфигурация из `js/firebase-config.js` предназначена для браузера и видна посетителям сайта. Firebase API key идентифицирует проект, но не даёт доступ к данным сам по себе. Не добавляй сюда service-account JSON или приватные серверные ключи.

Firebase Security Rules проверяются на сервере. App Check дополняет их и затрудняет использование базы сторонними скриптами, но не делает публичный клиент полностью доверенным и не подтверждает правдивость GPS-координат.

## Где хранятся данные

- Игровой прогресс (уровень, здоровье, предметы и экипировка) хранится локально в `localStorage` браузера. В Firebase сейчас отправляется только имя и текущая GPS-позиция для показа игроков рядом.
- Локальные сохранения можно изменить через инструменты браузера. Защищённо проверять игровой прогресс между устройствами можно только на доверенном сервере; шифрование ключом, вшитым в JavaScript, этого не обеспечивает.
- Firebase передаёт данные по HTTPS и шифрует их при хранении. Это защищает канал и носители Firebase, но не скрывает координаты от пользователей, которым правила разрешают читать `players`.
- Интерфейс показывает игроков в пределах 1 км, но клиентское ограничение расстояния не скрывает остальные записи от вошедшего в базу пользователя. Не используй этот прототип для чувствительных координат.

## GitHub Pages

Загружай весь репозиторий, сохраняя `index.html` в корне. Папки `css` и `js` должны быть рядом с ним. После публикации тестируй страницу по HTTPS.
