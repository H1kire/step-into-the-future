# Городские странники

«Городские странники» — небольшая GPS-RPG, в которой реальная прогулка становится приключением. Разреши доступ к геопозиции, исследуй карту и встречайся с монстрами.

## Возможности

- Путешествие по карте с GPS и учётом пройденного расстояния.
- Автоматическое появление монстров, пошаговые сражения и награды.
- Уровни, здоровье, энергия, экипировка, инвентарь и выпадение предметов.
- Древо улучшений на 250 узлов: характеристики героя, добыча и гибридные бонусы. За каждый новый уровень даётся 1 Ability Point.
- Онлайн-видимость игроков поблизости через Firebase. Чат пока доступен только между вкладками одного браузера.
- Интерфейс для компьютеров и телефонов. Прогресс сохраняется в браузере на устройстве.

## Защита и данные

Для показа игроков рядом используется защищённое соединение и вход в онлайн-службу. Доступ к онлайн-данным ограничивается настройками безопасности проекта. Игровое сохранение остаётся в браузере игрока. Геопозиция нужна для работы GPS-функций; делись ссылкой на игру только с теми, кому доверяешь.

## Запуск

Игра опубликована через GitHub Pages. Для GPS открой её по HTTPS и разреши браузеру доступ к геопозиции. Главный файл сайта — `index.html` в корне проекта.


## Облачное сохранение

Для пользователей, вошедших через Google, игровой прогресс синхронизируется с Firebase Realtime Database примерно раз в минуту и после важных сохранений. При первом входе существующее локальное сохранение переносится в облако; при последующих входах облачное сохранение загружается на устройство. На бесплатном тарифе Spark регенерация здоровья/энергии и появление монстров за время отсутствия рассчитываются при следующем открытии игры (расчёт ограничен 7 днями, максимум 60 монстров). После закрытия браузера Firebase Spark не запускает игровой мир в фоне.
